Lesson overview

Insignia and Ribbon Placement

Measure and place authorized insignia, ribbons, and the name tag using the current standard.

Learning objectives

  • Identify only the devices currently authorized for you.
  • Measure placement from the correct garment reference points.
  • Check alignment before fastening each item.

Prerequisites / required items

Assigned uniform shirt or coat, authorized devices, and a ruler.
